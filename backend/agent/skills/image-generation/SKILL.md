# 配图生成 Skill

## 工作流程

1. **读取文章内容**
   先读取文章全文，理解核心主题和调性。

2. **提取视觉元素**
   从文章中提取：
   - 核心主题/关键词
   - 情感基调（专业/轻松/温暖/科技感）
   - 主要场景或比喻

3. **生成图片 Prompt**
   根据目标平台构造不同 Prompt：

   ### 知乎封面（16:9 横版）
   ```
   prompt: "专业科技风格的插图，主题是 [核心主题]。
   扁平化设计，蓝色调为主，简洁大气。
   16:9 横版构图，适合文章封面。"
   width: 1024, height: 576
   ```

   ### 小红书首图（3:4 竖版）
   ```
   prompt: "温馨生活风格的插图，主题是 [核心主题]。
   马卡龙色系，可爱亲切，有文字留白区域。
   3:4 竖版构图，适合小红书封面。"
   width: 768, height: 1024
   ```

4. **调用 generate_image 工具**
   使用 `generate_image` 工具生成图片，保存到 `images/` 目录。

5. **返回结果**
   返回图片路径和简短描述。

## 图片质量要求

- 构图简洁，主体突出
- 色彩鲜明但不刺眼
- 不包含文字（文字由平台编辑器添加）
- 分辨率足够清晰
- 风格与文章调性一致

## 数量

- 知乎: 1 张封面图
- 小红书: 1-3 张配图（首图 + 内容图）
