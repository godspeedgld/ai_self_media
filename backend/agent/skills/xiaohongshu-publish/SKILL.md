# 小红书发布 Skill

## 内容准备

1. **读取确认版本**
   读取用户确认的文章版本文件。

2. **格式规范检查**
   - 标题 ≤ 20 字，有冲击力和好奇心
   - 正文 ≤ 1000 字
   - Emoji 使用自然（每段 1-2 个）
   - 文末有 3-5 个话题标签 (#话题)
   - 语气生活化、亲切

3. **准备配图**
   - 首图: 3:4 竖版（768x1024），最吸引人的一张
   - 总计: 1-9 张图片
   - 格式: jpg 或 png
   - 单张不超过 5MB

## 发布步骤

1. **调用发布工具**
   ```
   publish_to_xiaohongshu(
     title="笔记标题",
     content="正文内容（含 Emoji 和话题标签）",
     image_paths=["images/xhs_cover.png", "images/xhs_2.png"]
   )
   ```

2. **工具内部流程**
   a. 启动 Playwright 浏览器
   b. 检查登录状态
   c. 导航到小红书创作中心 (creator.xiaohongshu.com)
   d. 点击"发布笔记"
   e. 上传图片（按顺序，首图最重要）
   f. 填入标题（≤ 20 字）
   g. 填入正文
   h. 添加话题标签（点击 # 按钮选择推荐话题）
   i. 选择发布范围（公开/仅粉丝可见）
   j. 点击"发布"
   k. 等待并验证发布成功

3. **返回结果**
   - 成功: 笔记 URL
   - 失败: 错误信息 + 截图

## 错误处理

- **登录过期**: 提示用户在设置页面扫码重新登录
- **图片上传失败**: 检查图片格式和大小，重试上传
- **发布失败**: 截图保存、记录错误日志
- **内容被限流**: 提示用户检查是否包含敏感词

## 注意事项

- 小红书是图文笔记模式，图片质量决定点击率
- 首图最重要，决定了用户是否点击
- 话题标签选择与内容相关的热门标签
- 正文不要太长，用户更倾向于短内容
- 发布时间建议: 工作日 12:00-13:00 / 18:00-22:00
