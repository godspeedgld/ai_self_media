# 内容生成 Skill

## 工作流程

1. **研究先行（必须）**
   委派 `researcher` 子Agent 搜索相关资料：
   ```
   task(
     subagent_type="researcher",
     description="研究 [主题]。将研究结果保存到 research/[slug].md"
   )
   ```

2. **读取研究笔记**
   研究完成后，读取 findings 文件再开始写作。

3. **选择目标平台风格**
   - 知乎 → 长文风格
   - 小红书 → 短文风格
   - 未指定 → 默认生成长文版本

4. **生成文章**
   将文章保存到 `content/{project-slug}/draft_v{N}.md`

5. **生成配图**
   委派 `image-generator` 子Agent 生成配图

## 知乎风格要点

- **长度**: 1500-5000 字
- **格式**: 标准 Markdown
- **语气**: 专业、有深度、逻辑清晰
- **标题**: ≤ 50 字，体现核心观点
- **段落**: 每段 3-4 句话
- **Emoji**: 少用或不用
- **引用**: 使用 `>` 引用块标注来源
- **结构**: 引言 → 问题分析 → 核心观点 → 案例 → 总结

## 小红书风格要点

- **长度**: 300-800 字
- **格式**: 纯文本，少量 Markdown
- **语气**: 生活化、亲切、像朋友聊天
- **标题**: ≤ 20 字，要有冲击力和好奇心
- **段落**: 每段 1-2 句话
- **Emoji**: 每段 1-2 个，增加视觉节奏
- **话题标签**: 文末 3-5 个 (#话题)
- **结构**: 钩子开头 → 核心干货 → 行动号召 → 标签

## 迭代修改

当用户提供反馈时：
1. 读取当前版本内容
2. 根据反馈修改对应部分
3. 保存为新版本 `draft_v{N+1}.md`
4. 保持整体风格一致
