# 知乎发布 Skill

## 内容准备

1. **读取确认版本**
   读取用户确认的文章版本文件。

2. **格式规范检查**
   - 标题 ≤ 50 字，体现核心观点
   - 使用标准 Markdown 格式
   - 引用块 `>` 标注来源
   - 代码块使用语法高亮
   - 确保段落简短（每段 ≤ 4 句）

3. **准备配图**
   - 图片格式: jpg 或 png
   - 单张不超过 5MB
   - 封面图推荐 16:9 横版

## 发布步骤

1. **调用发布工具**
   ```
   publish_to_zhihu(
     title="文章标题",
     content="Markdown 正文",
     image_paths=["images/cover.png"]
   )
   ```

2. **工具内部流程**
   a. 启动 Playwright 浏览器
   b. 检查登录状态（如过期提示用户重新登录）
   c. 导航到知乎创作中心
   d. 选择"写文章"
   e. 填入标题
   f. 填入正文内容（支持 Markdown）
   g. 上传封面图
   h. 添加标签（最多 5 个）
   i. 点击"发布"
   j. 等待并验证发布成功

3. **返回结果**
   - 成功: 文章 URL
   - 失败: 错误信息 + 截图

## 错误处理

- **登录过期**: 提示用户在设置页面重新登录
- **发布失败**: 截图保存、记录错误日志、建议重试
- **网络超时**: 等待 30 秒后重试，最多 3 次
- **内容被拒**: 提示用户修改敏感内容

## 注意事项

- 知乎文章无字数上限，建议 1500-5000 字
- 标签最多 5 个，选择与内容相关的热门标签
- 发布后可在知乎后台编辑修改
- 支持定时发布（后续版本）
